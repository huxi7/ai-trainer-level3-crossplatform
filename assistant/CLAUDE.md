# assistant/
> L2 | 父级: ../CLAUDE.md

只在右键时截图。OCR 在首次识别时加载。
匹配器核对题干与全部选项，不使用源字母。
原生边界监听右键，不拦截系统菜单。
界面只绘制短暂浮字。独立入口打开设置。

成员清单
__init__.py: 定义桌面助手包边界。
config.py: 合并预设与本机配置，校验答案显示秒数，提供资源和日志路径。
bank.py: 从只读题库加载题目，定义共用文本规则与选项区域终点。
matching.py: 共用编辑距离容错，核对完整选项，输出最低匹配度和拒答原因。
ocr.py: 共用 mobile 模型，正文裁到题目列，实际按钮拼条识别后按位置合行。
layout.py: 共用题目列定位与按钮图像增强，归位居中的多行选项字母。
native.py: 定义右键事件和原生平台边界。
macos.py: macOS 输入监听、权限检查与窗口截图。
windows.py: Win32 右键与截图，统一 DPI 物理坐标，避免系统缩放截错范围。
ui.py: 主线程浮字与独立设置，答案定时消失，显示时长自动保存。
main.py: 单实例通信、按需识别与实时检查，记录具体拒答原因。
validation.py: 两平台共用本机离线截图回归入口，检查数字、否定词与缺项拒答。

[PROTOCOL]: 变更时更新此头部，然后检查 CLAUDE.md
